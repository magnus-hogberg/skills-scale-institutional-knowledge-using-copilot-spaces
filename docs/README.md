# OctoAcme Project Management Docs

This repository contains the core project management guidance for OctoAcme. Together, these documents define how the team initiates work, plans delivery, tracks execution, manages risks, releases software, and continually improves how work gets done. The goal is to create a repeatable, transparent process that helps cross-functional teams stay aligned from idea through delivery and retrospective.

OctoAcme’s project management approach is lightweight and iterative. Teams validate the business need and success metrics during initiation, turn approved ideas into a prioritized backlog during planning, and execute work in small, reviewable increments with clear ownership. Communication includes delivery-team standups, weekly syncs, stakeholder updates, demos, and escalation paths as needed. Quality is a shared responsibility, supported by CI tests and linting, unit and integration tests as appropriate, end-to-end smoke tests for critical flows, security scanning, and manual QA when needed. Releases include pre-release checks, deployment verification, and rollback planning; retrospectives turn lessons into owned, trackable improvements.

## Using these documents

Start with the [Project Initiation Guide](./octoacme-project-initiation.md) for a new initiative. Use the planning, execution, and risk guidance to coordinate delivery, then consult the release and retrospective guides to deploy safely and capture improvements. The [Project Management Overview](./octoacme-project-management-overview.md) provides a concise orientation to the full lifecycle.
